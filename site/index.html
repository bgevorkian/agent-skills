epub-ai-translate

Literary Russian translation for user-provided EPUB and text-layer PDF books. It keeps chapter context, shares a terminology glossary, resumes safely, preserves illustrations, rebuilds book-quality PDFs, and asks a second vision model to inspect every page.

  • EPUB → Russian EPUB + PDF
  • Text-layer PDF → reflowed Russian PDF
  • Whole-chapter / semantic-chunk translation
  • Deterministic checks + full-page vision review
